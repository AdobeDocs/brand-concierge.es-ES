# Configuración técnica y funciones opcionales

Prepare su sitio web para Adobe Brand Concierge y elija las funciones opcionales que respaldan su experiencia del visitante. Este vídeo cubre los requisitos de implementación, las formas de agregar el servicio de conserjería a su sitio y las integraciones para reservas de reuniones, chat en vivo y Marketo Engage.

## ¿Para quién es este vídeo?

* Desarrolladores y administradores de sitios web
* Equipos de tecnología de marketing

## Contenido de vídeo

* Requisitos de implementación: sistema de administración de etiquetas para fragmentos de código agregados manualmente, páginas de destino, zona protegida de Adobe Experience Platform, organización IMS y un conjunto de datos
* Añadir el conserje a su sitio web con un administrador de etiquetas o directamente en su base de código
* Configuración de la reserva de reuniones con representantes, disponibilidad y detalles de programación
* Habilitar el chat en vivo con disponibilidad de representantes, déclencheur de visitantes y reserva de reuniones
* Conectar Marketo Engage para recibir posibles clientes y actividades, con acceso de administrador y un indicador de funcionalidad
